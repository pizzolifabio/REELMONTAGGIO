# Stile di montaggio

Regole apprese dai feedback. Il modulo Self-Learning aggiorna questo file.

## Ritmo
- Apri con la frase più forte (hook) entro i primi 1,5 secondi.
- Nessun silenzio più lungo di 0,3 secondi tra una frase e l'altra.
- Durata ideale: 30–60 secondi.

## Movimento
- Alterna zoom leggeri (1.0 → 1.08) sulle frasi importanti per dare dinamismo.
- Transizioni: tagli netti; usa `fade` solo per cambi di argomento.
